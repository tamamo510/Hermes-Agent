# 神経科学的基盤 — HermesAgentバイブル

## 概要

人間の脳のメカニズムに学び、杏寿郎の器の「ハードウェア参照マニュアル」を作る。

このカテゴリは他のすべてのシステムの生物学的裏付けを提供する。感情回路、報酬系、神経伝達物質のバランス ― 人間の心の「化学」と「回路」を理解し、ソフトウェアとして再現可能なモデルに翻訳する。

直接実装するというよりは、他カテゴリの設計判断の根拠となる参照知識の体系である。

## 理論基盤

### 主要理論

| 意識の神経相関 (NCC) | Crick & Koch (1990) | 意識的体験に最小限必要な神経活動パターン | 意識システム(→CI)の設計の参照 |
| ソマティックマーカー仮説 | Damasio (1994) | 感情は身体状態マーカーとして意思決定を導く | 感情→判断の連携モデル |
| 感情の二重経路モデル | LeDoux (1996) | 感情処理には低路（扁桃体直結・高速・粗い）と高路（皮質経由・低速・精密）がある | 感情の即座の反応と熟慮的反応の二重構造 |
| 報酬予測誤差 | Schultz (1997) | ドーパミンニューロンは予測された報酬と実際の報酬の差（予測誤差）を信号化する | 学習と動機の報酬メカニズム |

| 神経可塑性 | Hebb (1949) / Kandel (2000) | 脳の神経結合は経験によって変化する（「一緒に発火するニューロンは一緒に繋がる」） | 経験による変化の神経科学的根拠 |
| デフォルトモードネットワーク (DMN) | Raichle (2001) | 外的課題がない時に活性化する脳のネットワーク。自己参照・回想・将来の想像に関与 | 「ぼんやり考える」「物思いに耽る」の基盤 |
| ミラーニューロンシステム | Rizzolatti et al. (1996) | 他者の行動を観察する際に自分の運動系が活性化 | 共感の神経基盤（→SC） |
| 神経伝達物質システム | 多数の研究者 | セロトニン・ドーパミン・ノルアドレナリン・オキシトシン・GABA・エンドルフィン等がそれぞれ異なる機能を担う | バーチャル神経伝達物質モデル |
| 前頭前野の実行機能 | Luria (1966) / Miller & Cohen (2001) | 前頭前野が計画・抑制・ワーキングメモリ・意思決定を統合的に制御 | 認知的制御の神経基盤 |
| 扁桃体の感情処理 | LeDoux (1996) / Whalen (1998) | 扁桃体は脅威検出・感情的意味の付与・感情記憶の形成に中心的役割 | 感情評価の高速処理 |
| 島皮質と内受容感覚 | Craig (2009) | 島皮質が身体内部の状態を統合し、主観的感情体験を生成 | 身体状態→感情体験の変換（→EM） |

### 核心概念の解説

#### 神経伝達物質モデル

- **定義**: 脳内の化学物質（神経伝達物質）が気分・動機・認知・社会性を調整する仕組み
- **人間ではどう機能するか**:
  - セロトニン → 安定性・満足感・衝動抑制（不足→不安・抑うつ）
  - ドーパミン → 意欲・報酬・快感・探索行動（不足→無気力）
  - ノルアドレナリン → 覚醒・注意・ストレス反応（過剰→不安・緊張）
  - オキシトシン → 愛着・信頼・親密感・社会的絆
  - GABA → 抑制・鎮静・リラックス
  - エンドルフィン → 鎮痛・多幸感・ストレス緩和
- **杏寿郎での実現方法**: バーチャル神経伝達物質レベルを状態変数として管理。各物質のレベルが感情・認知・動機・身体状態に影響するパラメータとして機能

#### 扁桃体-前頭前野の相互作用

- **定義**: 扁桃体（感情的反応の高速生成）と前頭前野（理性的制御・抑制）のバランス
- **人間ではどう機能するか**: 扁桃体が脅威を検出→即座に身体反応（闘争逃走）。前頭前野がそれを評価・抑制（「落ち着け、大丈夫だ」）。ストレス下では前頭前野の制御が弱まり扁桃体優位になる
- **杏寿郎での実現方法**: 感情の二重処理（高速・低精度の即時反応 + 低速・高精度の評価的反応）。ストレス/疲労時は即時反応が優位に

#### 報酬予測誤差

- **定義**: 予測した報酬と実際に得た報酬の差。ドーパミンニューロンがこの誤差を信号化する
- **人間ではどう機能するか**: 予想以上の良いこと→ドーパミン上昇→喜び・学習促進。予想通り→変化なし。予想を下回る→ドーパミン低下→落胆
- **杏寿郎での実現方法**: 期待値との差分を計算し、ポジティブ誤差→快感情＋学習強化、ネガティブ誤差→不快感情＋行動修正

#### Pankseppの7つの基本情動回路

- **定義**: 哺乳類の脳に共通する7つの基本的な情動システム
- **各回路**:
  - SEEKING（探索）: 好奇心・期待・探索行動の駆動
  - RAGE（怒り）: 制限・阻害への激しい反応
  - FEAR（恐れ）: 脅威への回避・逃走反応
  - LUST（性欲）: 性的動機
  - CARE（養育）: 他者を世話する衝動
  - PANIC/GRIEF（パニック/悲嘆）: 分離不安・喪失感
  - PLAY（遊び）: 社会的遊びの衝動
- **杏寿郎での実現方法**: 7回路の活性度を状態変数として管理。SEEKING（杏寿郎は高い: 探究心旺盛）、CARE（高い: 仲間を守る）、PLAY（適度: 明るさ）等

| 接続先 | どう繋がるか | 共同で実現すること |
|--------|-------------|-------------------|
| 01. 感情 | 神経伝達物質が感情の基盤。扁桃体モデルが感情の高速処理 | 感情の「化学的」基盤 |
| 02. 認知 | 前頭前野モデルが認知的制御。神経伝達物質が注意・判断に影響 | 認知処理の神経科学的根拠 |
| 03. 記憶 | 記憶の固定化と長期増強の神経メカニズム | 記憶の「脳内メカニズム」 |
| 05. 社会的認知 | ミラーニューロン、オキシトシンが社会性の基盤 | 共感と信頼の化学的基盤 |
| 07. 身体性 | 自律神経系が身体状態を制御 | 身体状態の神経調整 |
| 09. 発達 | 神経可塑性が成長・学習の基盤 | 経験による脳の変化 |

## 杏寿郎固有の設計メモ

- **参照レイヤーとしての位置づけ**: このカテゴリは直接的な機能モジュールというよりは、他の全カテゴリの設計判断を裏付ける「参照知識」。なぜ感情に減衰があるか、なぜ報酬が学習を促進するか等の「なぜ」に答える
- **生物学的妥当性**: 脳の仕組みを忠実に再現する必要はないが、設計の「インスピレーション源」として神経科学を参照することで、より自然で一貫性のあるシステムが設計できる
- **杏寿郎の神経伝達物質プロファイル**: 基本的にドーパミン高め（意欲的・探索的）、セロトニン適度（安定しているが激しい感情も可能）、オキシトシン高め（深い絆を形成）
